## 1. 상속 vs 포함

**1.1 상속 관계 (Inheritance / Is-A)**

- "A는 B이다" (예: `Dog is a Animal` / 강아지는 동물이다)
- 자바에서는 `extends` 키워드를 사용하여 부모의 특징을 물려받음.

**1.2 포함 관계 (Containment / Has-A)**

- "A는 B를 가지고 있다" (예: `Car has a Engine` / 자동차는 엔진을 가지고 있다)
- 클래스 내부에 다른 객체를 필드(멤버 변수)로 선언해서 부품처럼 사용하는 모든 경우를 뜻함.
- '포함 관계'는 ***두 객체가 얼마나 강력하게 묶여있는가(생명주기 결합도)***에 따라 다시 두 갈래로 나뉨.
    - **어그리게이션 (Aggregation):** 약한 포함 (각자 독립적으로 생존 가능)
    - **컴포지션 (Composition):** 강한 포함 (완벽한 운명 공동체)

---

## 2. 합성(Composition) vs 집합(Aggregation)

한국어로 공식적으로 정해진 용어가 딱히 없는듯. → 그냥 영어로 부르자

### 2.1 공통점

- **포함 관계 (Has-A):** 두 개념 모두 한 클래스가 다른 클래스의 인스턴스를 '필드(멤버 변수)'로 가지고 있는 상태
- **목적:** 상속(Is-A)의 끈끈하고 경직된 단점을 피하고, 객체들을 부품처럼 조립하여 코드의 재사용성과 유지보수성을 높이기 위해 사용

### 2.2 차이점

| **구분** | **생명주기 (Lifecycle)** | **결합도** | **비유** | **자바 객체 생성 방식** |
| --- | --- | --- | --- | --- |
| **어그리게이션** | **독립적** (전체가 사라져도 부분은 남음) | 약함 | `팀(Team)`과 `팀원(Member)` | **외부**에서 생성 후 주입받음 |
| **컴포지션(조합)** | **종속적** (전체가 사라지면 부분도 사라짐) | 강함 | `집(House)`과 `방(Room)` | **내부**에서 직접 생성함 (`new`)  |

## 3. 어그리게이션 (Aggregation)

전체 객체와 부분 객체가 포함 관계를 맺지만, **부분 객체가 전체 객체와 독립적으로 존재할 수 있는 약한 결합**

- **특징:** 전체 객체가 메모리에서 소멸되더라도 부분 객체는 파괴되지 않고 다른 곳에서 계속 사용될 수 있음(필수까진 아님)
- **코드 작성 패턴:** 주로 생성자의 매개변수(Parameter)를 통해 외부에서 이미 생성된 객체를 전달받아 필드에 세팅. (= 의존성 주입, DI)

```java
// 부분 객체
class Member {
    private String name;
    public Member(String name) { this.name = name; }
}

// 전체 객체
class Team {
    private List<Member> members;

    // [핵심] 외부에서 만들어진 Member 리스트를 매개변수로 받아옵니다.
    // Team이 해체(소멸)되어도 Member 객체들은 메모리에 그대로 살아남습니다.
    public Team(List<Member> members) {
        this.members = members;
    }
}
```

## 4. 컴포지션 (Composition)

전체 객체와 부분 객체의 **생명주기가 완벽하게 일치하는 강한 결합**.

- **특징:** 부분 객체는 오직 전체 객체 안에만 존재하며, 전체 객체가 소멸할 때 부분 객체도 함께 가비지 컬렉터(GC)에 의해 메모리에서 지워짐.
- **코드 작성 패턴:** 외부에서 객체를 받아오지 않고, 전체 객체의 **생성자 내부에서 부분 객체를 직접 `new` 키워드로 생성**

```java
// 부분 객체
class Room {
    private String roomName;
    public Room(String roomName) { this.roomName = roomName; }
}

// 전체 객체
class House {
    private Room livingRoom;
    private Room bedRoom;

    // [핵심] House가 생성될 때 내부에서 Room을 직접 생성(new)합니다.
    // House가 철거(소멸)되면 내부의 Room 객체들도 함께 운명을 다합니다.
    public House() {
        this.livingRoom = new Room("거실");
        this.bedRoom = new Room("침실");
    }
}
```
