## 1. 문자열의 출력: `toString()` vs `deepToString()`

---

- 배열에 저장된 모든 요소를 문자열 형태로 편리하게 출력하고 싶을 때 사용한다.

### 📝 Arrays.toString()

- **용도**: 1차원 배열의 요소를 문자열로 변환한다.
- **특징**: 배열의 각 요소를 대괄호`[]` 안에 쉼표`,`로 구분하여 보여준다.
- **제한**: 다차원 배열에 사용할 경우, 내부 배열의 값들이 아닌 **내부 배열의 주소값**이 출력된다.

### 📝 Arrays.deepToString()

- **용도**: 다차원 배열(2차원 이상)의 모든 요소를 문자열로 변환한다.
- **특징**: 배열의 모든 요소를 재귀적으로 접근하여 구성하므로, 2차원뿐만 아니라 3차원 이상의 고차원 배열에서도 동작한다.

```
int[] arr = {0, 1, 2, 3, 4};
int[][] arr2D = {{11, 12}, {21, 22}};

// 1차원 배열 출력
System.out.println(Arrays.toString(arr));     // 출력: [0, 1, 2, 3, 4]

// 다차원 배열 출력 (deepToString 사용 필수)
System.out.println(Arrays.deepToString(arr2D)); // 출력: [[11, 12], [21, 22]]
```

## 2. 배열의 비교: `equals()` vs `deepEquals()`

---

- 두 배열에 저장된 데이터가 동일한지 확인하고자 할 때 사용한다.

### 📝 Arrays.equals()

- **용도**: 1차원 배열 간의 비교를 수행한다.
- **작동 방식**: 두 배열의 모든 요소를 하나씩 비교하여 같으면 `true`, 다르면 `false`를 반환한다.
- **제한**: 다차원 배열 비교 시, 내용물이 같더라도 `false`를 반환할 가능성이 높다.

### 📝 Arrays.deepEquals()

- **용도**: 다차원 배열 간의 비교를 수행한다.
- **작동 방식**: 다차원 배열의 모든 요소를 재귀적으로 비교하여 실제 저장된 내용이 같은지 확인한다.

```
String[][] str2D =  new String[][]{{"aaa", "bbb"}, {"AAA", "BBB"}};
String[][] str2D2 = new String[][]{{"aaa", "bbb"}, {"AAA", "BBB"}};

// equals()로 비교 시 (잘못된 결과)
System.out.println(Arrays.equals(str2D, str2D2));     // 결과: false

// deepEquals()로 비교 시 (정확한 내용 비교)
System.out.println(Arrays.deepEquals(str2D, str2D2)); // 결과: true
```

## 3. 💡 왜 다차원 배열에서는 `equals()`가 실패할까?

---

이 부분은 자바의 메모리 구조와 **'배열의 배열'** 개념을 이해하는 것이 중요하다.

1. **배열의 배열 (Array of Arrays)**: 자바에서 다차원 배열은 독립된 공간이 아니라, '배열을 요소로 갖는 배열'이다. 즉, 2차원 배열의 첫 번째 레벨에는 실제 데이터가 아닌, 하위 1차원
   배열들의 참조값(Address)이 저장되어 있다.
2. **주소 비교 (Reference Comparison)**: 다차원 배열에 `Arrays.equals()`를 사용하면, 배열 안에 저장된 '내용물'을 비교하는 것이 아니라 '배열에 저장된 하위 배열들의
   주소값'을 비교하게 된다.
3. **결과**: 서로 다른 두 배열 객체는 메모리상에서 항상 다른 주소에 생성되므로, 내부의 데이터 값이 완벽히 일치하더라도 주소값이 다르기 때문에 항상 `false`라는 결과가 나오게 된다.

따라서 다차원 배열의 실제 값을 비교하고 싶다면 반드시 Deep Comparison(깊은 비교)을 수행하는 `Arrays.deepEquals()`를 사용해야 한다.

### 📌 요약

---

| **구분**     | **1차원 배열**          | **다차원 배열 (2차원 이상)**     |
|------------|---------------------|-------------------------|
| **문자열 출력** | `Arrays.toString()` | `Arrays.deepToString()` |
| **내용 비교**  | `Arrays.equals()`   | `Arrays.deepEquals()`   |
