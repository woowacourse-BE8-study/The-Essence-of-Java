# 이진 검색 트리 vs 레드 블랙 트리
## 1. 레드 블랙 트리

레드 블랙 트리란 자가 균형 이진 탐색 트리이다.

```plaintext
- 모든 노드는 빨간색 혹은 검은색이다.
- 루트 노드는 검은색이다.
- 모든 리프 노드(NIL)들은 검은색이다. 
   (NIL : null leaf, 자료를 갖지 않고 트리의 끝을 나타내는 노드)
- No Double Red(빨간색 노드가 연속으로 나올 수 없다)
- 모든 리프 노드에서 Black Depth는 같다.
```

(1) 새로 삽입되는 노드는 항상 빨간색이다. <br>
(2) 삼촌 노드가 검은색이라면 -> Restructuring을 수행하면 된다. <br>
(3) 삼촌 노드가 빨간색이라면 -> Recoloring을 수행하면 된다. <br>

## 2. 이진 검색 트리 vs 레드 블랙 트리

### (1) BST가 유지하는 것 = 정렬 순서

BST 규칙:

```
왼쪽 < 부모 < 오른쪽
```

BST는 순서대로 삽입된다.

```
8 → 3 → 10 → 6 → 7
```

트리:

```
        8
       / \
      3   10
       \
        6
         \
          7
```

만약 이렇게 삽입하면

```
1 → 2 → 3 → 4 → 5
```

BST 구조:

```
1
 \
  2
   \
    3
     \
      4
       \
        5
```

- 정렬은 유지된다.

- 하지만 트리 높이가 너무 크다.

- 시간복잡도로 `O(n)`이다.

→ 사실상 LinkedList


### (2) Red-Black Tree는 균형까지 자동 유지

같은 데이터를 넣어도 레드 블랙 트리는 자동으로 구조를 바꿔서 균형 유지한다.

```
1 → 2 → 3 → 4 → 5
```

```
      3
     / \
    2   4
   /     \
  1       5
```

- 높이가 낮다. → 탐색 빠르다.

- 시간복잡도 `O(log n)`
-> 항상 보장된다.


### (3) 정리

| 특징 | BST | Red-Black Tree |
| --- | --- | --- |
| 정렬 유지 | O | O |
| 균형 유지 | X | O |
| 최악 성능 | O(n) | O(log n) |
| 자동 재구성 | X | O |
